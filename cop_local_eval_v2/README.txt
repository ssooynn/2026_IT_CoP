CoP 결과발표회 로컬 평가시스템 v2
=================================

[실행 방법]
1. 이 폴더의 압축을 풉니다.
2. Windows에서는 start_server.bat를 더블클릭합니다.
   또는 명령 프롬프트에서 python app.py 를 실행합니다.
3. 담당자 노트북과 심사위원 노트북을 같은 Wi-Fi에 연결합니다.
4. 실행 화면에 표시되는 심사위원 접속 주소를 공유합니다.
   예) http://192.168.0.15:5000
5. 관리자 화면: http://담당자IP:5000/admin
   기본 관리자 PIN: 1234

※ Windows 방화벽 안내가 나오면 '개인 네트워크'에 대해 Python 통신을 허용해야
   같은 Wi-Fi의 다른 노트북에서 접속할 수 있습니다.

[이번 버전 반영사항]
1. 최종 제출 시 빈 점수가 하나라도 있으면 제출되지 않습니다.
   알림: "모든 값을 입력해주시기 바랍니다."
2. 임시저장 기능을 추가했습니다.
   일부 점수만 입력해도 저장할 수 있고, 같은 심사위원명으로 재접속하면 이어서 작성합니다.
3. 관리자 화면에서 임시저장/제출완료 상태와 입력 개수를 확인할 수 있습니다.
4. 관리자 화면에서 평가자별 팀 총점과 항목별 원점수를 모두 확인할 수 있습니다.
5. 최종 점수는 '제출 완료' 심사위원만 사용합니다.
6. 각 팀에 대해 심사위원별 팀 총점 중 최고점 1개, 최저점 1개를 각각 제외하고
   나머지 점수의 평균을 산정 점수로 계산합니다.
   - 제출 완료 심사위원이 3명 미만이면 산정 대기 상태로 표시됩니다.
7. 관리자 화면의 '팀별 점수·순위 저장' 버튼을 누르면 현재 산정 점수 기준으로
   확정 순위를 저장하고 별도 구간에 표시합니다.
8. 이후 평가가 추가/수정되더라도 저장된 순위는 자동 변경되지 않습니다.
   최신 결과로 다시 확정하려면 '팀별 점수·순위 저장' 버튼을 다시 누릅니다.
9. Excel 다운로드에는 평가자별 원점수와 현재 팀별 산정 결과가 함께 포함됩니다.

[기존 버전에서 업데이트하는 경우]
- 기존 폴더의 cop_scores.db 파일은 삭제하지 마세요.
- 새 app.py로 교체한 뒤 다시 실행하면 기존 점수를 그대로 사용합니다.
- 기존 버전에서 48개 항목이 모두 저장된 심사위원은 '제출 완료',
  일부만 저장된 심사위원은 '임시저장'으로 자동 분류합니다.

[데이터 파일]
- 평가 데이터는 실행 폴더의 cop_scores.db에 저장됩니다.
- 행사 중에는 이 파일을 삭제하거나 이동하지 마세요.
